# Project Paradox

**It's all in your perspective.**

A calm, single-player 3D puzzle set in two connected dimensions. Switch worlds to discover a bridge and a Cube; use a warp device to transfer the Cube, then solve the White Dimension's pressure-plate puzzle.

## Run

1. Open this folder in **Unity 6000.6.7f1** (Built-in rendering, legacy Input Manager).
2. Open `Assets/Scenes/Level01.unity`.
3. Press Play and click the Game view.
4. Use **WASD**, **mouse**, **Space**, **E**, **Q**, and **R** for movement, look, jump, interaction, dimension switch, and restart. Escape releases the cursor; click to resume.

The scene and project settings were generated by the installed Unity editor, not handwritten. To regenerate the primitive level, use **Paradox > Build Level 01**. This replaces Level01 after a confirmation; it keeps existing material assets. To produce a Linux executable, use **Paradox > Build Linux Player**.
